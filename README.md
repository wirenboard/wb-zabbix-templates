# wb-zabbix-templates

Wiren Board device templates for Zabbix.

Готовые шаблоны Zabbix для мониторинга устройств Wiren Board по MQTT через Zabbix Agent 2.

## Что внутри

- `templates/` — готовые Zabbix-шаблоны по моделям устройств WB (YAML, формат импорта Zabbix 7.0).

## Требования

- Zabbix 7.0 LTS или новее.
- Zabbix Agent 2 со встроенным MQTT-плагином (рекомендуется 7.0.10+ / 6.0.39+).
- Сетевой доступ от агента к MQTT-брокеру контроллера Wiren Board.

## Как использовать

1. В Zabbix: Data collection → Templates → Import — выбрать YAML нужной модели из `templates/`.
2. Создать хост под устройство и привязать импортированный шаблон.
3. На хосте задать макросы:
   - `{$MQTT.BROKER}` — адрес MQTT-брокера контроллера (например, IP контроллера `127.0.0.1`, если агент на самом контроллере)
   - `{$DEVICE}` — slug устройства в MQTT (`<модель>_<slave_id>`, например `wb-mr6cu_23`)
   - `{$MQTT.PORT}` — порт брокера (по умолчанию `1883`, добавлять, если порт отличается)
4. Имя хоста должно совпадать со строкой `Hostname` (`ZBX_HOSTNAME` в Docker) агента — master-элемент это активная проверка, агент собирает её только для своего имени.

Значения контролов появятся в Latest data, ошибки контролов (`/meta/error`) мониторятся отдельными элементами и триггерами.
